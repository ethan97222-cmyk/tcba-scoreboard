# TCBA 瓶蓋棒球記分板

專為瓶蓋棒球現場轉播設計的網頁記分系統。紀錄員控制台與大螢幕透過 Socket.IO 即時同步，SQLite 保存每場比賽及整個賽會的球員數據。

## 安裝與啟動

需要 **Node.js 24**（使用內建 `node:sqlite`）與 npm。

```sh
npm ci
npm start
```

- 控制台：<http://localhost:3000/control.html>
- 大螢幕：<http://localhost:3000/display.html>
- OBS 透明背景：<http://localhost:3000/display.html?transparent=1>

程式啟動後保持運作。重複啟動時會提示連接埠已被使用。

## 功能

- 客／主隊隊名、隊徽、代表色與完整打序編輯。
- 每隊 1–40 人，守位為 DH、C、RF、LF、P；背號需為 0–999 且不可重複。
- 隊徽上傳、打序調整、JSON 名單匯入匯出、試算表批次貼上。
- 好球、壞球、界外球，1B、2B、3B、HR、BB、K、GO、FO。
- 自動壘包推進、得分、第三出局換局，以及手動修正與復原。
- 依得分顯示 1／2／3 RUN HOMER、GRAND SLAM，支援逆轉及再見特效。
- 正規局數、是否延長、延長局數上限與自動比賽結束。
- 打者、下一棒、場上投手，以及本場與賽會的 K、BB、用球等數據。
- 兩隊左右分欄的賽後結算、勝敗投手、勝利打點及全壘打球員名單。
- 歷史比賽接續、完整 SQLite 備份及賽會 JSON 匯出。

## 基本操作

1. 在「隊伍與球員」編輯兩隊，按「儲存並同步」。
2. 指定兩隊先發投手與局數；先發預設取 P 守位，換投時選擇新的場上投手。
3. 開啟大螢幕，紀錄員在控制台逐球記錄。
4. 結束比賽後建立同一賽會的下一場，歷史資料與賽會累計會保留。

安打預設每位跑者推進相同壘數，其他情況用壘包與加減分按鈕修正。保送只推進被迫進壘的跑者。直接記安打或出局會計入最後一球；直接 BB 只完成打席，逐球記保送請按四次壞球。

批次貼上每行一位球員，支援逗號或 Tab 分隔：

```text
24,球員甲,LF
39,球員乙,RF
```

## 賽會資料與備份

程式自動建立 `scoreboard.sqlite`，保存賽會、球員、每場快照及每場統計；`scoreboard-data.json` 作為目前比賽的備援存檔。第一次從舊 JSON 遷移時會保留 `.before-sqlite` 副本。

同一賽會、隊名、姓名、背號會認回同一球員。請保持拼寫一致；改名、改號或換隊目前不自動合併。球員賽會累計包含已結束比賽與本場。其他未結束比賽仍保存，可從歷史紀錄接續。

AVG = H / AB；BB 計入 PA，不計入 AB。投手歷史缺漏會標記，不會猜測。勝投採取得且維持最終領先時的在任投手；敗投採致勝分責任投手；勝利打點採造成該分的打者。此為本系統的瓶蓋棒球結算方式，不套用傳統棒球先發最低局數或後援勝投裁量規則。

使用控制台的「備份完整資料庫」下載一致的 SQLite 快照。還原前先停止程式，保留舊檔並將備份放回專案根目錄、改名為 `scoreboard.sqlite`；不要覆寫使用中的資料庫。

**GitHub 只保存程式碼，不保存你的實際賽會資料。** 資料庫、JSON 存檔、日誌與開發預覽圖片均已排除。先前未保存且已清空的比賽無法還原；可匯入本系統下載的完整已結束比賽 JSON。

## 手機、平板與雲端

區網使用時，手機與電腦連同一 Wi-Fi，開啟控制台列出的電腦區網網址；手機不能使用電腦的 `localhost`。電腦需持續開機。

上傳 GitHub 不代表網站已上線。正式公開部署前，需要另外加入控制台登入與權限檢查；SQLite 必須放在持久磁碟並定期備份。

可設定環境變數：

| 變數 | 用途 |
| --- | --- |
| `PORT` | 網頁連接埠，預設 `3000` |
| `SCOREBOARD_DATA_FILE` | JSON 備援檔案路徑 |
| `SCOREBOARD_DB_FILE` | SQLite 資料庫路徑 |

## 驗證

```sh
npm test
```

測試涵蓋記分、保送、換局、全壘打、延長賽、復原、投手責任、自動結算、跨場累計、匯入去重、重啟及 SQLite 備份。測試使用獨立暫存資料，不會改動正式賽會資料。

## 檔案

- `server.js`：Express、Socket.IO、記分事件與存檔。
- `statistics.js`：責任投手、致勝分與投手統計。
- `database.js`：SQLite、球員身分及賽會累計。
- `public/`：控制台、大螢幕與樣式。
- `test-*.js`：驗證程式。
